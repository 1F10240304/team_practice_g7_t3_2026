## 他のPCと同じデータで動かす

依頼などのデータは各PCの `db.sqlite3` に保存されるため、PCごとに `runserver` すると別々のデータになります。
1台を「サーバー役」にして、他のPCはそこへアクセスしてください。

1. サーバー役のPCで `python manage.py runserver 0.0.0.0:8000` を実行する
2. サーバー役のPCの IPアドレスを `ipconfig` で調べる（例: 172.16.247.42）
3. 他のPCのブラウザで `http://<IPアドレス>:8000/` を開く

※ つながらないときは、サーバー役のPCの Windows ファイアウォールで Python の通信を許可してください。
※ `http://IPアドレス` で開いたページではマイク（音声入力）が使えないことがあります。そのときは文字で入力してください。
